# ひと日（hitohi）— Android

Android 8.0 以降向けのローカルアプリ。端末の Calendar Provider に同期された予定を読み取り、日別の縦長アジェンダとホーム画面ウィジェットに表示します。Google カレンダーへの直接ログインや独自サーバーはありません。Google 以外の表示中のカレンダーも対象です。

## ビルド

Android Studio でこのフォルダーを開き、JDK 17以上、Android SDK Platform 35、Build Tools 35.0.0 を用意してください。SHA-256 を固定した Gradle Wrapper 8.11.1 を同梱しています。Android Gradle Plugin は 8.9.2 です。

```sh
./gradlew :app:assembleDebug :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Google Maven、Maven Central、Gradle 配布元への接続が必要です。SDK パスを設定する `local.properties` はコミットしないでください。

## 使い方

1. Android の設定で Google アカウントのカレンダー同期を有効にし、端末のカレンダーアプリで予定が見えることを確認します。未同期の予定は読み込めません。
2. 本アプリでカレンダーの読み取りを許可します。拒否後はアプリ内の設定ボタンから権限を変更できます。
3. 前日・今日・翌日で日付を切り替えます。アプリ内の予定をタップすると端末のカレンダーアプリで詳細が開きます。
4. アプリの追加ボタン、またはホーム画面のウィジェット一覧から追加します。推奨サイズは 3 × 5 セル。縦横のリサイズとスクロールに対応します。

ウィジェットは常に今日を表示します。更新ボタンとアプリ表示時に更新し、約30分の定期更新と日付・タイムゾーン変更時の更新に対応します。省電力制御により更新は遅れる場合があります。同期自体は Android 側の設定に従います。

## プライバシー

権限は `READ_CALENDAR` のみ。インターネット権限や書き込み権限はありません。独自サーバーへの送信や予定の永続コピーは行いません。予定名と場所はホーム画面に表示されます。

Android SDK と JDK / Gradle を導入し、署名付きリリース APK のクリーンビルド・リリース版 Lint・署名検証に成功しています。実機動作は未確認です。

## ブラウザでデザインを確認

`web/index.html` をブラウザで開くか、リポジトリのルートから `python3 -m http.server 8000 --directory web` を実行してください。外部依存はありません。日付切り替え、予定詳細、アプリ／ウィジェット表示、スマートフォン幅に対応しています。日曜日は空の状態、土曜日は私用中心のサンプルを表示します。Google カレンダーへの接続は行いません。

Chromium で予定6件、詳細ダイアログ、翌日移動、表示切り替え、空の日、390px幅で横にはみ出さないこと、JavaScript エラーなしを確認しました。

## 公開

- GitHub Pages: リポジトリの Settings → Pages → Source を **GitHub Actions** に設定。`main` に `web/` の変更を push すると `Publish browser preview` が公開します。初回は Actions から手動実行も可能です。

## 時間軸の表示

- アプリ・ウィジェット・ブラウザデモは、0:00〜24:00 を1時間あたり72dp（ブラウザでは72px）の固定縮尺で表示します。空き時間を詰めず、縦スクロールで1日全体を確認できます。
- 予定の縦位置と高さは開始・終了時刻に比例します。重複する予定は横に並べ、日付をまたぐ予定は当日の範囲で切り取ります。終日予定は時間軸の外に表示します。
- 赤線は今日だけに表示します。ブラウザは毎秒、Android アプリは毎分更新。ホーム画面ウィジェットは OS の更新制約があるため、赤線は最後のウィジェット更新時点を示します（手動更新可能）。
- 夏時間のある地域でも時刻ラベルの高さは一定です。秋の繰り返す時間帯で終了時刻が開始時刻より前になる予定は、実経過時間を使って高さを補います。

検証: `sh scripts/test-timeline.sh` は JDK 17以上で時間配置のテストを実行します。今回の環境では JRE のみのため、Maven Central のチェックサムを照合した Eclipse ECJ で同じ実装とテストをコンパイル・実行し、終日分離、予定の長さの比率、重複配置、隣接、日またぎ、空の日が通過しました。正式版準備時には JDK でも同じテストを再実行し通過しています。署名付き APK のビルドと Lint は成功し、実機動作は未確認です。

`python3 scripts/test-browser.py` は Python Playwright と `/usr/bin/chromium` がある環境で、25個の時刻ラベル、等間隔、予定の高さ、現在時刻線の移動、別の日で線が消えること、予定詳細、空の日、ウィジェット切り替え、モバイル幅を検証します。画面画像はデフォルトで `/tmp/calendar-preview` に保存します（`SCREENSHOT_DIR` で変更可能）。

# calendar-widget v1.0.3

時刻と現在時刻線の毎分更新、文字と予定の境界のデザインを改善しました。

## 毎分更新の使い方

1. 更新 APK を上書きインストールし、アプリを開きます。
2. 「時刻と赤線を毎分更新」を ON にして、通知を許可してください。
3. 常駐通知が表示されている間、画面点灯中は毎分の境界で赤線を更新します。時計には Android 標準の時計部品を使います。
4. 通知の「停止」またはアプリ内スイッチで終了できます。

画面消灯中は処理を休止し、点灯時にすぐ最新時刻へ合わせます。端末を定期的に起こすアラームやウェイクロックは使いません。通信やサーバー利用料は発生しません。

再起動・アプリ更新後もON設定を引き継いで再開を試みます。OSやメーカーの省電力制御、ユーザーによる強制停止によりサービスが止まる場合があります。その場合はアプリを開いて再開してください。常駐サービスを使わない場合でも時計は更新され、赤線には最終更新時刻を表示します。

## デザイン

- 予定の輪郭を淡い0.5dpに変更し、左端の色アクセントも細くしました。同色の連続予定は区別しつつ、枠線の主張を抑えています。
- タイトルの太さと余白を調整。短い予定ではタイトルを優先し、長いタイトルには折り返し・省略表示を使います。
- ウィジェットの上部に読みやすい現在時刻を表示。赤線も細くしました。
- 0〜24時の固定縮尺と、予定の時間に比例する高さは維持しています。

## 配布とプライバシー

Android 8.0以上向けの署名付き APK です。v1.0.2 と同じアプリ ID・署名鍵で上書き更新できます。表示が更新されない場合は、ウィジェットの更新ボタンを押すか、ウィジェットを追加し直してください。

カレンダーは読み取りのみ。毎分更新のために通知・フォアグラウンドサービス・再起動通知の権限を追加しました。インターネット権限はなく、予定を外部へ送信しません。

毎分タイマー・通知の開始停止・消灯復帰・Androidの描画と時計レイアウトの15テストが通過しました。ビルド・Lint（エラー0件）・署名も検証済みです。実機・ホームアプリ固有の省電力挙動は未確認です。結果は添付の `calendar-widget_release.json` に記録します。

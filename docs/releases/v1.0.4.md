# calendar-widget v1.0.4

ウィジェットで夕方〜夜以降の一覧が途中で切れ、24:00までスクロールできない問題を修正しました。

## 修正内容

新しい Android では、一日分のウィジェット画像の合計容量が上限を超えると、一覧が途中までしか渡されない場合があります。画像1枚ごとの容量制限では防げなかったため、Android 12以降のウィジェットを、文字・図形の標準部品による表示へ変更しました。画像を縮小して画質を落とす方式ではなく、文字も画面密度に合わせて直接描画します。

複数のウィジェットサイズで使える転送容量も考慮し、サイズ候補を整理しました。0〜24時の固定縮尺、毎分更新、予定の高さ、細い境界線は維持しています。Android 11以前では従来の画像表示を使用します。

## 更新方法

`calendar-widget-v1.0.4.apk` を上書きインストールしてください。アプリ ID と署名鍵は変更していません。「時刻と赤線を毎分更新」の設定も引き継ぎます。

古い一覧が残る場合はウィジェットの更新ボタンを押してください。変わらない場合は、ホーム画面のウィジェットを一度削除して追加し直してください。端末のカレンダーの予定は削除されません。

## 検証

- Android の合計画像容量制限を再現した条件でも、一日分の49区間と終日予定が最後まで渡されること。
- 20:00〜24:00の目盛り、23:45〜24:00の予定、23:58の現在時刻線。
- Android 8 / 現行 Android のリストで最下部までスクロールでき、更新後も末尾の位置を維持すること。
- 複数サイズの転送量、毎分更新、通知の開始停止、既存の描画・時間配置。

21テストが通過し、Lintはエラー0件です。実機固有のホームアプリでの動作は未確認です。テスト・Lint・署名の結果は `calendar-widget_release.json` に記録します。

# calendar-widget v1.0.1

端末に同期されたカレンダーを、0〜24時の縦長タイムラインで確認できる Android アプリの初回リリースです。

## インストール

1. `calendar-widget-v1.0.1.apk` を Android 端末へダウンロードします（Android 8.0以上）。
2. ファイルを開き、必要に応じて使用中のブラウザ／ファイルアプリからのインストールを許可します。
3. 「calendar-widget」を開き、カレンダーの読み取りを許可します。
4. Android の Google アカウント設定でカレンダー同期を有効にします。ホーム画面のウィジェット一覧から「calendar-widget」を追加できます。

パッケージ名は `io.github.wassanborn72.calendarwidget` です。旧開発版（`com.example.daycalendar`）とは別アプリとしてインストールされます。予定データ自体は端末のカレンダーにあるため、本アプリへ移行する必要はありません。

## 機能

- 日付切り替えと0〜24時の固定縮尺タイムライン
- 予定の所要時間に比例した高さ、重複予定の横並び
- 今日の現在時刻を赤線で表示
- 終日・複数日・繰り返し予定の読み取り
- 縦にスクロールできるホーム画面ウィジェット
- カレンダーの読み取りのみ。独自サーバーへの予定送信はありません

## 制限

ウィジェットの赤線は最終更新時点を示します。Android の省電力制御により定期更新は遅れる場合があるため、最新表示が必要な場合は更新ボタンを押してください。端末に同期されていない予定は読み込めません。カレンダー選択と予定編集は未対応です。

署名付きの直接配布 APK です。Google Play での配布・審査は行っていません。端末固有の同期設定やホームアプリの違いを含む実機動作は未確認です。


## 検証結果

署名付きリリース APK のクリーンビルド、リリース版 Lint（エラー0件、Android 31以降のウィジェット属性に関する互換性警告2件）、APK の署名・アプリ ID・バージョン・チェックサム検証、時間配置テスト、ブラウザ版の操作テストに成功しています。実機でのインストール・同期・ウィジェット動作は未確認です。

同梱の `calendar-widget_SHA256SUMS` と `calendar-widget_PUBLIC_CERTIFICATE_SHA256.txt` で APK と署名証明書を照合できます。配布ファイルに秘密鍵やパスワードは含みません。

旧 v1.0.0 タグは公開前 CI で停止したため、アプリ名を統一した v1.0.1 を配布版とします。

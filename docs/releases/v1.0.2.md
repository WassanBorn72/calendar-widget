# calendar-widget v1.0.2

Android ウィジェットの画質と、予定どうしの境界の見やすさを改善した更新です。

## 改善点

- 端末の画面密度に合わせた高解像度・フルカラー描画に変更。低解像度画像の拡大による文字や線のぼやけを抑えます。
- Android 12以降はウィジェットのサイズごとに適切な横幅で描画。旧バージョンでも縦横の向きを考慮します。
- 同じカレンダーの予定が連続しても分かるよう、上下左右の枠線と角丸を追加。時刻ラベルのコントラストも改善しました。
- 終日予定のカードにも枠線を追加。ブラウザのデザイン確認版も同じ境界表現に更新しました。
- 0〜24時の固定縮尺、予定の開始・終了位置と高さ、現在時刻線は維持しています。

高解像度画像は短い区間に分割し、各画像の転送量に上限を設けています。非常に大きいウィジェットや高い画面密度では、安定性のため画像解像度に上限が適用されます。

## 更新方法

`calendar-widget-v1.0.2.apk` をダウンロードし、v1.0.1 に上書きインストールしてください。同じアプリ ID・署名鍵を使用しています。ウィジェット表示が以前のままの場合は更新ボタンを押してください。ホームアプリが古いレイアウトを保持する場合は、一度ウィジェットを削除して追加し直してください。

Android 8.0以上に対応しています。Google Play を使わない署名付き APK の直接配布です。端末のカレンダー読み取り権限が必要で、予定の外部送信は行いません。

## 制限と検証

ウィジェットの現在時刻線は最終更新時点を示します。実機・ホームアプリ固有の描画は未確認です。Android 描画エンジンによる画像テスト、時間配置テスト、ビルド・Lint・署名検証、ブラウザ操作テストの結果を同梱の `calendar-widget_release.json` に記録します。

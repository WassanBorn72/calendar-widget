# calendar-widget v1.0.7

予定をタップして Google カレンダーの該当予定を開けるようにしました。

## 予定を開く

- ウィジェットの予定カードをタップすると、その予定の詳細を Google カレンダーで開きます。
- 予定が横に重なっている場合も、タップしたカードの予定 ID を渡します。
- 終日予定にも対応し、繰り返し予定は選択した回の開始・終了時刻を渡します。
- アプリ内のタイムライン・終日予定も Google カレンダーを優先して開きます。
- Google カレンダーがない、または起動できない場合は端末の対応カレンダーアプリを使用します。対応アプリがない場合はメッセージを表示します。

Android 11以前のウィジェットは画像表示のため、同じ表示区間に複数の予定がある場合は選択一覧を表示します。1件の場合は直接その予定を開きます。予定のない区間は無効です。

端末に同期された予定 ID を使うため、削除済み・未同期の予定や、Google カレンダー側で参照できない予定は開けない場合があります。予定の作成・変更や、独自の外部サーバーへの送信は行いません。

## 更新

`calendar-widget-v1.0.7.apk` を上書きインストールしてください。同じアプリ ID・署名鍵を使い、毎分更新設定も維持します。ウィジェットのタップが反応しない場合は更新ボタンを押し、必要に応じてウィジェットを追加し直してください。

## 検証

ウィジェットホストでの各カードのタップ、予定 ID・日時の受け渡し、Google カレンダー優先、代替アプリ、終日予定、重複予定の選択、旧 Android の PendingIntent と既存表示を含む50テストが通過しました。Lintはエラー0件です。実機の Google カレンダーアプリとの連携は未確認です。結果は `calendar-widget_release.json` に記録します。

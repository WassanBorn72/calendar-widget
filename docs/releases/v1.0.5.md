# calendar-widget v1.0.5

ウィジェット更新時に予定・目盛り・現在時刻線が重なって残る問題を修正しました。24:00までの表示は維持しています。

## 原因と修正

ウィジェットの行を再利用して更新する際、既存の表示部品を消さずに新しい部品を追加していました。毎分更新や手動更新のたびに古い内容が残るため、行の部品を置き換えてから最新の内容を描画するよう修正しました。

予定の編集・削除、スクロールによる行の再利用、リサイズ・日付変更でも古い内容を残しません。更新時には一覧のキャッシュ識別子も切り替え、旧方式の行を持ち越さないようにしています。

現在時刻の数字は上部の時計にまとめ、時間軸では固定の時刻目盛りと赤線を表示します。正時付近に現在時刻の数字を重ねて描くことをやめ、目盛りどうしの衝突も防ぎました。

## 検証

修正前は再適用の4テストで重複を再現し、修正後は通過しています。繰り返し更新、予定の編集・削除、行の再利用、日付変更・リサイズ、転送後の更新画像と新規描画の一致、正時付近の目盛りを検証しています。0〜24時の一覧転送・末尾スクロール・毎分更新などを含む26テストが通過し、Lintはエラー0件です。

実機固有のホームアプリでの動作は未確認です。結果は `calendar-widget_release.json` に記録します。

## 更新方法

`calendar-widget-v1.0.5.apk` を上書きインストールしてください。アプリ ID・署名鍵・毎分更新設定は引き継ぎます。更新後にアプリを開くかウィジェットの更新ボタンを押してください。ホームアプリが旧表示を保持している場合は、ウィジェットを一度削除して追加し直してください。カレンダーの予定は削除されません。
